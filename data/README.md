# Data

`subscriptions-churn.csv` is not included in this repository because it contains customer records.
Place it here locally before running the analysis.

Expected columns (Arabic headers, as in the source file):

| Column | Meaning |
|---|---|
| معرف المشترك | Subscriber ID |
| تاريخ الاشتراك | Subscription date |
| الباقة | Package tier (أساسي / متقدم / أعمال) |
| السعر الشهري | Monthly price |
| دورة الفوترة | Billing cycle (شهري / سنوي) |
| أشهر البقاء | Tenure in months |
| وسيلة الدفع | Payment method (بطاقة / محفظة / تحويل) |
| تذاكر الدعم | Support tickets |
| متوسط الجلسات الشهرية | Average monthly sessions |
| نسبة الخصم | Discount (percentage points) |
| حضر التهيئة | Attended onboarding (نعم / لا) |
| ألغى الاشتراك | Churned (نعم / لا) |
